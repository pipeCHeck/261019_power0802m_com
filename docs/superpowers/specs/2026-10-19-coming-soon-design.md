# power0802m.com 제작 중 페이지

- 목적: 정식 사이트를 준비하는 동안 방문자를 맞는 가벼운 한 화면.
- 구성: 따뜻한 흰색 바탕, 중앙 한국어 작업 문구, 작은 도메인 표기.
- 글꼴: 중앙 전환 문구에는 사용자가 제공한 `SB 어그로 L.TTF`를 자체 호스팅 웹폰트로 적용한다. 원본 Light 글자 형태를 유지하며, 나머지 문구는 기존 시스템 글꼴을 사용한다.
- 문구: 첫 번째부터 사용자가 제공한 다섯 문구를 순서대로 반복한다. 문구 유지 시간은 2400ms, 전환은 650ms다. GIF 참고와 같이 이전 문구는 아래로 내려가고 다음 문구는 위에서 들어온다. 다섯 번째 다음에는 첫 번째로 돌아간다. 뒤의 점은 원래보다 1.5배 빠른 약 366.7ms 간격으로 `.`, `..`, `...`를 반복한다.
- 표현: 후속 사용자 요청에 따라 모션그래픽과 캐릭터를 제외한다. 문구는 겹친 그리드 레이어로 배치해 모바일에서도 전환 중 영역 높이가 변하지 않는다. 동작 줄이기 설정에서는 현재 문구와 점의 변화를 멈춘다. 하단 문구와 버튼은 제거하고 맨 아래 가운데에 `power0802m@naver.com` 메일 링크만 표시한다.
- 구현: 외부 의존성 없는 정적 HTML/CSS/JavaScript, 배포 파일은 `public/`에 둔다. JavaScript가 없어도 기본 안내 문구가 보인다.
- 배포: Cloudflare Pages에서 원격 Git 저장소를 연결하고 `public`을 출력 디렉터리로 지정한다. 운영 브랜치에 push하면 자동 배포한다. 실제 계정 연결과 도메인 설정은 계정 접근 후 진행한다.
- 확인: 실제 브라우저에서 다섯 문구의 순서와 마지막→첫 번째 반복, 점 순환, 모바일 전환 시 높이 유지, 동작 줄이기, JavaScript 비활성화와 콘솔 오류를 확인한다.
