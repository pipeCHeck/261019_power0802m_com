# 공 살려두기

- 기존 페이지 위에서 작동하는 공 게임. 후속 크기·그래픽 요구사항은 `2026-10-19-drag-game-design.md`를 따른다. 기본 지름은 36px이며 드래그로 바꿀 수 있다. 채워진 공과 점수는 색을 반전시키고 클릭 효과·폭죽은 가는 불투명 선을 사용한다. 메뉴, 배경 패널, 시작·종료 창은 없다.
- 빈 화면을 누른 채 드래그하면 윤곽선 크기 미리보기를 표시한다. 놓는 순간 정한 크기로 공을 위로 띄운다. 점수는 0이다.
- 떨어지는 공을 클릭하면 다시 위로 튕기며 점수가 1 증가한다. 접촉점이 공 중심의 왼쪽이면 오른쪽 위, 오른쪽이면 왼쪽 위로 튀며 중심 클릭은 수직이다. 작은 클릭 오차를 허용한다.
- 벽과 천장에서는 공이 반사된다. 공이 화면 하단 밖으로 떨어지면 종료한다. 다시 빈 곳을 클릭하면 새 게임이 시작된다.
- 모든 게임 클릭에 얇은 별 모양 선 이펙트를 표시한다. 선은 투명해지는 대신 짧아져 사라진다. 공을 놓친 클릭은 점수와 공의 운동을 바꾸지 않는다.
- 점수는 커서의 오른쪽 위에 작게 표시하며 화면 가장자리에서는 화면 안에 유지한다. 10, 20, 30점 등에서 커서 주변에 작은 단색 선 폭죽을 한 번 표시한다.
- 숫자의 등장·변경, GG 전환·퇴장은 중앙 문구와 같은 650ms 세로 슬라이드를 사용한다. GG는 전환 완료 후 1초 유지한 뒤 아래로 사라진다. 재시작하면 이전 GG의 종료 타이머를 취소한다.
- 게임 캔버스와 점수는 클릭을 가로채지 않는다. 기존 링크·선택 가능한 입력 컨트롤의 클릭은 게임에서 제외한다.
- 동작 줄이기 설정에서는 장식 파문·폭죽과 점수 슬라이드를 생략한다. 직접 시작한 공의 물리는 유지한다. 탭이 숨겨지면 물리를 일시정지하며 크기 변경에는 공을 화면 안으로 보정한다.
- 아래 안내 문구는 기존보다 3px 더 위로 이동한다. 원래 속도의 1.5배인 점 애니메이션과 순차 문구 전환은 유지한다.

## 구현과 확인

- `game-physics.mjs`: 입력·물리·점수를 다루는 독립 모델, Node 내장 테스트 사용.
- `game.js`: 캔버스 렌더링, 포인터 이벤트, 점수 슬라이드, 파문·폭죽·수명 처리.
- `game.css`: 공의 색 반전, 가는 선 효과와 작은 점수 레이어. 기존 스타일과 분리한다.
- 확인 항목: 처음 0, 낙하 중 재타격 증가, 좌우 방향, 빗나감, 10점 단위 폭죽, 실패 GG와 퇴장, 재시작 타이머, 모바일·동작 줄이기·탭 숨김·화면 크기 변경, 기존 문구와 이메일 유지.
