# 확률 도형과 회전

- 사용자가 확인한 대상은 폭죽이 아니라 새 공의 모양이다. 원80%, 하트10%, 별10%의 서로 배타적인 구간을 사용한다.
- 드래그 시작 시 한 번 선택해 윤곽선 미리보기에도 적용한다. 마우스를 놓을 때 재추첨하지 않는다.
- 하트와 별은 SVG 경로로 만들며, 기존 색 반전과 점수 합성을 유지한다. 도형의 중심을 기준으로 경로 자체를 회전시켜 크기 미리보기의 레이아웃은 변하지 않는다.
- 비행 중 부드럽게 감쇠하는 회전, 좌우 타격에 따른 회전 충격, 벽·천장 충돌 시 반전을 적용한다. 충격 순간 각도를 초기화하지 않아 회전이 끊기지 않는다.
- 회전 적분은 프레임 속도에 독립적이며 충돌·타격 판정은 기존 원형 범위와 허용 여유를 유지한다.
- 기존 드래그 크기·점수·GG·10점 폭죽·점수 폰트·문구 전환은 유지한다.
- 하트 경로를 중심 기준으로 정규화해 회전해도 원형 충돌 경계를 넘지 않도록 했다. 원래 경로가 반경을 초과하는 회귀 테스트의 실패를 확인한 뒤 보정했다.
- 검증: 확률 경계·1000개 균등 구간의80/10/10분배, 도형 시작·회전, 하트 경로의 경계, 타격 각도의 연속성, 회전 프레임 독립성 및 천장 반전을 포함한16개 테스트가 통과한다. Node DOM 드라이버로 도형의 단일 추첨·드래그 미리보기·출시 후 모양과 회전 적용도 확인했다. 실제 경로와 물리 각도로 네이티브 캔버스 미리보기를 렌더링하고 도형을 확인했다. Work 설정에서 로컬 브라우저 제어가 꺼져 있어 이번 변경의 브라우저 직접 확인은 수행하지 않았다.
