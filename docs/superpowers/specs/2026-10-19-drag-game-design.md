# 드래그 공 크기와 그래픽 개선

- 점수·GG·크기 표시는 제공된 SB 어그로 L 폰트를 자체 호스팅으로 적용한다. 흰 글자에 difference 합성을 적용해 밝은 배경에서는 검정, 검정 공과 겹치면 흰색으로 보이게 한다.
- 아래 안내 문구는 현재보다 1px 아래로 내린다.
- 유휴/종료 상태에서 기본 포인터를 누르면 공 크기 지정이 시작된다. 누른 지점이 중심이고 드래그 거리가 반지름이다. 지름은 16~320px이며 작은 화면에서는 화면에 맞게 상한을 줄인다.
- 4px 미만의 짧은 움직임과 빠른 클릭·탭은 기존 지름 36px을 유지한다. 드래그 중에는 윤곽선 공과 커서 옆 `60px` 같은 실제 지름을 표시하고 아직 점수와 물리는 시작하지 않는다.
- 마우스/터치를 놓으면 선택한 크기로 공이 위로 발사되고 크기 표시가 0점으로 슬라이드 전환된다. 재타격·점수·폭죽·GG·재시작은 기존 규칙을 유지한다.
- 드래그 중 포인터가 링크 위나 화면 바깥 좌표로 이동해도 포인터 캡처로 크기 지정/해제가 이어지며, 공 크기와 중심은 화면 안에 들어오도록 제한한다. 포인터 취소, 캡처 분실, 창의 포커스 상실, Escape, 탭 숨김은 미완성 공을 취소한다. 링크에서 처음 누른 경우에는 게임을 시작하지 않는다.
- 클릭 파문 원은 8개의 짧은 불투명 선으로 된 별 모양으로 교체한다. 선은 밖으로 이동하며 길이가 줄어든다. 폭죽도 알파 페이드 없이 선 길이를 줄여 사라지게 한다.
- 동작 줄이기 설정에서는 장식 이펙트와 슬라이드를 생략한다. 터치 드래그와 창 크기 변경을 지원한다.

## 구현

- `game-physics.mjs`: 반지름 선택 및 화면 크기 제한, 사용자 지정 크기로 시작, 크기 변경 시 재보정.
- `game.js`: sizing/playing 상태, 포인터 캡처와 취소, 실시간 크기 미리보기, 불투명 선 이펙트.
- `game.css`: M 폰트·점수 합성·윤곽선 미리보기.
- 확인: 물리 테스트, 누름/드래그/놓음 단계, 취소와 재시작 타이머, M 폰트의 실제 로드, 배경·공·텍스트 위 점수 합성 픽셀, 이펙트 불투명도, 모바일 터치, 기존 게임 회귀.

## 검증 결과

- 크기 관련 새 테스트의 실패를 확인한 후 구현했고, 물리 테스트 11개가 통과했다.
- 브라우저에서 윤곽선 미리보기, 지름 표시, 놓을 때 시작, 실제 M 폰트 렌더링과 검정 공 위 흰 점수 픽셀, 선의 alpha=1을 확인했다.
- native touch 드래그·해제·취소를 확인했다. 상단·하단 빈 영역에서 터치 드래그가 취소되던 문제를 재현하고 전체 페이지의 touch-action을 수정해 통과시켰다.
- 별도 검토에서 미완성 공을 취소하는 애니메이션 도중 동작 줄이기 설정을 바꾸면 크기 표시가 남는 문제를 발견했다. 재현 테스트의 실패를 확인하고 퇴장 상태를 보존하도록 수정해 통과시켰다.
- 기존 재타격·10점·GG·재시작, 30/60fps, 문구 순서·점 애니메이션·반응형 레이아웃 회귀 검사를 통과했다.
