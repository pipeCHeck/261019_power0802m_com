# power0802m.com

중앙 문구와 점 애니메이션으로 구성된 제작 중 페이지입니다. 모션그래픽은 사용하지 않습니다. 외부 패키지·이미지·폰트 요청 없이 작동합니다.

## 미리 보기

Node.js 22 이상에서 실행하세요. 간단한 파일 미리보기에는 패키지 설치가 필요 없습니다.

```sh
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 종료는 터미널에서 `Ctrl+C`입니다.

## Cloudflare Workers + Git 자동 배포

GitHub 저장소는 `https://github.com/pipeCHeck/261019_power0802m_com`, 운영 브랜치는 `master`입니다. 이 브랜치에 **push**하면 Workers Builds가 배포하도록 연결합니다.

`wrangler.jsonc`의 Worker 이름은 `power0802m-com`, 파일 경로는 `./public`입니다. 운영 주소는 `https://power0802m.com`이며 Custom Domain 경로를 설정 파일에도 기록했습니다. 운영 `workers.dev` 주소는 대시보드의 현재 설정에 맞춰 비활성화했습니다. Workers Static Assets로 HTML·CSS·JS·폰트를 제공하며 별도의 서버 코드나 사이트 빌드는 필요하지 않습니다. 기존 `_headers`의 응답 헤더와 캐시 설정도 사용합니다.

1. Cloudflare의 **Workers & Pages → Create application**에서 **GitHub 저장소 연결 / Import a repository**로 새 **Worker**를 만듭니다.
2. `pipeCHeck/261019_power0802m_com`을 선택합니다. GitHub 앱 권한에 해당 저장소가 포함되어 있어야 합니다.
3. 다음 값으로 설정합니다.

   | 설정 | 값 |
   | --- | --- |
   | Worker 이름 | `power0802m-com`（Wrangler 설정과 동일） |
   | 운영 브랜치 | `master` |
   | Build command | 비워 두기 |
   | Deploy command | `npm run deploy` |
   | Root directory | 기본값, 저장소 루트 |
   | Node.js | 22 이상（필요 시 빌드 환경 변수 `NODE_VERSION=24`） |

4. 배포 후 운영 주소 `https://power0802m.com`에서 사이트를 확인합니다.
5. `power0802m.com`은 Wrangler의 Custom Domain 설정으로 연결·유지합니다. 도메인은 같은 Cloudflare 계정에 있어야 합니다. 대시보드에서 확인할 때는 Worker의 **Settings → Domains & Routes**를 엽니다. `www`도 사용할 경우 별도로 추가합니다.
6. Worker와 도메인의 정상 동작을 확인한 후 기존 Pages 프로젝트를 정리할 수 있습니다.

이후에는 다음 흐름으로 사이트가 갱신됩니다.

```sh
git add public package.json package-lock.json wrangler.jsonc
git commit -m "Update coming-soon page"
git push
```

Worker의 Builds/Deployments에서 해당 커밋의 배포 성공을 확인합니다. 최초 Workers Builds 연결과 사용자 도메인 연결은 Cloudflare 계정에서 진행해야 합니다.

Workers 환경으로 미리 보거나 배포 설정을 검사할 때는 아래 명령을 사용합니다. 직접 배포하는 `npm run deploy`에는 Cloudflare 인증이 필요합니다.

```sh
npm ci
npm run deploy:check
npm run preview:worker
```

Workers 미리보기 주소는 `http://127.0.0.1:8787`입니다. `deploy:check`는 실제 공개 배포를 하지 않습니다.

## 수정할 파일

- `public/index.html`: 화면 구성, 순서대로 전환할 다섯 문구, 제목·설명
- `public/styles.css`: 색상·크기·반응형 레이아웃
- `public/app.js`: 문구 유지 시간(2400ms), 전환 시간(650ms), 점 애니메이션 간격(550 / 1.5 ≈ 366.7ms)
- `public/favicon.svg`: 브라우저 탭 아이콘
- `public/fonts/sb-aggro-light.ttf`: 사용자가 제공한 SB 어그로 L 폰트. 중앙 전환 문구 및 크기·점수·GG 표시에 웹폰트로 적용
- `public/_headers`: Cloudflare Workers Static Assets 응답 헤더와 캐시 재검증
- `wrangler.jsonc`: Workers 이름, 호환성 날짜, 정적 파일 경로
- `public/game-physics.mjs`: 공의 중력·반사·타격 방향·점수 판정
- `public/ball-shapes.mjs`: 원·하트·별의 모양 및 생성 확률
- `public/game.js`, `public/game.css`: 공 크기 드래그, 커서 점수·색 반전, 불투명한 별 모양 클릭 효과·10점 폭죽
- `public/card-physics.mjs`, `public/card.js`, `public/card.css`: 사각형의 무게감·회전·바닥 접촉, 드래그 및 화면 좌우 연결
- `public/world-physics.mjs`, `public/scene.js`: 공과 사각형의 충돌 계산 및 공통 애니메이션 시간 관리
- `public/physics-config.mjs`: 사각형·공·하트·별이 공유하는 중력 기준
- `public/floor-effects.mjs`: 바닥 충돌 강도·접촉 폭·접선 속도에 따른 만화풍 충돌 섬광·파편·먼지

첫 번째 문구부터 제공된 순서대로 계속 전환됩니다. 문구를 2.4초간 보여 준 뒤, 0.65초 동안 이전 문구는 아래로 내려가고 다음 문구는 위에서 들어옵니다. 다섯 번째 다음에는 첫 번째 문구로 이어집니다. 전환 시간 변경 시 `styles.css`의 `message-enter`·`message-leave` 애니메이션 시간도 함께 바꾸세요.

모든 문구가 같은 공간을 공유해 전환할 때 화면이 위아래로 흔들리지 않습니다. 뒤의 점은 `. → .. → ...`로 계속 바뀝니다. 운영체제의 동작 줄이기 설정에서는 현재 문구와 `...`를 고정 표시합니다. JavaScript를 끄면 첫 번째 문구가 표시됩니다. 하단 가운데에는 일반 텍스트 이메일 `power0802m@naver.com`과 사이트 버전이 표시됩니다.

## 사이트 버전

사이트 수정 요청 하나를 완료할 때마다 `npm run version:bump`를 한 번 실행합니다. `package.json`, `package-lock.json`, 하단 표시의 마지막 숫자가 함께 올라갑니다(예: v0.0.1 → v0.0.2). 중간 저장이나 미리보기 열기에는 버전을 올리지 않습니다. 이후 작업에서도 이 규칙을 따르도록 `AGENTS.md`에 기록했습니다. 배포할 때는 수정한 `public`, `package.json`, `package-lock.json`을 함께 커밋하세요.

## 공 살려두기

빈 곳을 누른 채 드래그하면 윤곽선 공의 크기를 정할 수 있습니다. 누른 지점이 중심이며 드래그 거리가 반지름입니다. 커서 오른쪽 위에는 `60px`처럼 실제 지름이 표시됩니다. 지름은 16~320px이며 작은 화면에서는 상한이 줄어듭니다. 드래그 없이 짧게 클릭·탭하면 기본 지름 36px을 사용합니다.

손을 놓으면 공이 채워져 위로 튀고 크기 표시가 `0`점으로 전환됩니다. 공은 겹치는 부분의 색을 반전시켜 밝은 배경 위에서는 어둡고, 어두운 글자 위에서는 그 부분만 밝게 보입니다. 떨어지는 공을 다시 클릭할 때마다 1점씩 올라갑니다. 공의 왼쪽을 누르면 오른쪽 위로, 오른쪽을 누르면 왼쪽 위로 튕깁니다. 중앙을 누르면 수직으로 올라갑니다.

새 공은 원 80%·하트 10%·별 10% 확률로 생성됩니다. 모양은 드래그를 시작할 때 한 번 정해지고 미리보기부터 게임 종료까지 유지됩니다. 하트와 별은 비행 중 회전하며, 클릭한 쪽과 벽 충돌에 따라 회전 방향·속도가 달라집니다.

점수와 종료 문구는 SB 어그로 L 폰트와 색 반전을 사용하며 검정 공과 겹치면 흰색으로 보입니다. 클릭할 때는 불투명한 8방향 선이 바깥으로 튀면서 짧아집니다. 10점마다 24개의 더 길고 선명한 선이 두 차례에 걸쳐 퍼지는 폭죽이 약 1.05초간 표시됩니다. 공을 놓치면 원은 `GG`, 하트는 `LOVE`, 별은 `STAR`로 바뀌었다가 기존 슬라이드 효과로 사라집니다. 빈 곳을 다시 드래그해 새 게임을 시작합니다. 크기 지정 중 Escape, 포인터 취소, 창의 포커스 상실은 미완성 공을 취소합니다. 기존 링크는 게임 클릭에서 제외되며 별도 메뉴·패널·게임 화면은 없습니다.

동작 줄이기 설정에서는 선 이펙트·폭죽과 점수 슬라이드를 생략합니다. 탭을 숨기면 공의 운동이 일시정지됩니다. 터치 기기에서는 한 손가락 드래그로 크기를 정하며 두 손가락 확대는 유지합니다. 점수는 마지막 터치 위치의 오른쪽 위에 표시됩니다.

물리와 점수 테스트는 패키지 설치 없이 `npm test`로 실행합니다.

## 움직이는 사각형

검은 테두리와 투명한 내부에 제목·설명을 표시합니다. 문구는 `public/index.html`의 `physics-card`에서 바꿀 수 있습니다. 카드의 누른 지점을 잡고 드래그하면 무게중심이 따라 회전하고, 놓으면 중력을 받아 바닥에 머무릅니다. 좌우 끝을 넘어간 부분은 반대편에서 이어집니다. 화면 위에는 사각형을 막는 벽이 없으며, 위로 던진 사각형은 중력으로 돌아옵니다.

공중에서는 이동·회전 감속을 작게 유지하고, 손을 놓을 때도 움직이던 속도를 이어갑니다. 바닥은 화면 맨 아래와 일치합니다. 바닥에 선 카드를 아래로 누르면 잡은 지점이 바닥의 지지를 받으며 멈추고, 커서를 따라가려고 갑자기 다른 각도로 바뀌지 않습니다.

바닥 마찰은 실제 접촉 충격에 비례하며 중력을 중복해서 더하지 않습니다. 착지 때는 작게 튕기고, 옆으로 움직이던 속도와 회전도 접촉을 통해 점차 줄어듭니다. 바닥에서 떨어져 나가는 순간에는 옆방향 마찰이 추가로 걸리지 않습니다.

기본 바닥 충돌 효과는 이전 D **각진 파쇄**(`fracture`)입니다. 날카로운 충격 조각과 속이 빈 다각형 파편을 사용하며 충돌마다 형태와 궤적이 달라집니다. 비교 화면에서 선택한 D2 연쇄 파열과는 별개의 스타일입니다. 다른 비교안인 A 만화 구름은 먹색과 배경색을 사용한 만화풍 섬광, 크기가 다른 파편, 외곽선이 있는 먼지 구름으로 표현합니다. 섬광은 약 0.03초 안에 퍼진 뒤 짧게 걷히고 파편과 먼지가 이어집니다. 긴 단일 타격선이나 바닥을 가로지르는 지그재그는 사용하지 않습니다. 충돌 에너지·속도가 클수록 섬광과 파편이 커지고 많아지며, 모서리는 실제 접촉점에 모이고 넓은 면은 접촉 폭에 따라 나뉘어 퍼집니다. 충돌마다 먼지 구름의 돌출부·개수·비율과 섬광·충격파의 형태·시작 시점·지속 시간을 따로 생성합니다. 좌우 구름도 서로 다른 윤곽으로 굴러가며, 재생 중에는 생성한 형태를 유지해 깜빡임을 방지합니다. 옆으로 스치는 속도는 파편과 먼지·충격파의 방향과 퍼지는 거리에 반영하며, 화면 좌우 경계에서도 이펙트가 이어집니다. 드래그 중의 충돌도 표시하지만 정지 상태의 지지력이나 미세한 흔들림에는 반복해서 나오지 않습니다. 동작 줄이기 설정에서는 충돌 이펙트를 생략합니다.

잡고 있는 동안에는 판의 크기와 잡은 위치에 맞춰 관성·중력 토크·회전 감쇠가 계속 적용됩니다. 회전 감쇠는 임계 감쇠의 약 30%로, 무게중심을 지나 좌우로 흔들린 뒤 진폭이 점차 줄어듭니다. 커서 정지를 감지해 재생하는 별도 애니메이션이나 각도 고정은 없습니다. 움직이던 판을 새로 잡으면 잡은 지점을 기준으로 속도가 바뀝니다. 드래그 위치는 바로 따라가며 공중의 이동 감속은 작게 유지합니다.

커서를 작은 원으로 움직이면 이동 방향이 바뀌는 양을 회전력에 반영해 판을 휘두를 수 있습니다. 시계·반시계 방향 모두 가능하며, 반대로 돌리면 회전 방향도 바뀝니다. 미세한 떨림은 최근 이동 범위와 속도로 걸러냅니다. 커서를 멈추면 보정력이 줄어들고 기존 관성·중력·감쇠로 이어지며, 놓을 때의 회전 속도는 유지합니다.

사각형·공·하트·별은 3200 px/s²의 같은 중력 기준을 사용합니다. 정지 상태에서 400px 낙하하는 데 약 0.5초입니다. 사각형을 잡고 있을 때의 흔들림에도 같은 중력을 적용합니다. 공의 첫 발사 높이는 유지하고, 클릭으로 다시 튕길 때의 상승 높이는 기존보다 약 10% 높였습니다. 사각형은 바닥에서 거의 멈춘 뒤 남는 미세한 흔들림을 없애고 평평하게 정지합니다.

원·하트·별은 회전 중인 카드 및 화면 반대편에 표시된 부분과 충돌합니다. 충돌은 공과 사각형의 이동·회전에 영향을 주지만 클릭 점수를 올리지는 않습니다. 카드 드래그는 공 생성 입력과 구분되며, 카드에 키보드로 초점을 맞춘 뒤 방향키로 움직일 수도 있습니다. 탭을 숨기면 두 오브젝트의 물리 계산이 함께 멈춥니다.

## 충돌 이펙트 비교

바닥 충돌 지점 위에는 실제 수직 충돌 속도를 `600.0px/s`처럼 소수점 한 자리까지 표시합니다. 이동과 회전을 합친 접촉점의 충돌 직전 속도이며, 공 게임의 점수와 같은 서체를 사용합니다. 검은 사각형 안의 흰 숫자가 0부터 최종 값까지 항상 650ms 동안 올라갑니다. 값에 맞춰 박스 폭을 미리 정해 카운트 중에는 폭이 흔들리지 않으며, 박스와 숫자가 함께 위에서 들어오고 아래로 퇴장합니다. 표시 높이는 이메일 중앙 높이 근처에서 약 20px 범위로 달라집니다. 충돌마다 독립된 숫자 효과를 만들며 새 표시가 가장 앞에 나옵니다. 새 박스와 기존 박스의 중심 가로 거리가 45px 이내이고 높이 차이가 16px 이내이면 기존 박스는 180ms 동안 빠르게 퇴장합니다. 이미 등장한 박스는 아래로 이동하고, 아직 등장 중인 박스는 현재 위치를 고정한 채 보이는 부분만 지워서 빠르게 등장하는 듯한 역방향 이동을 방지합니다. 새 숫자는 재사용된 컨테이너에서도 새 텍스트 요소로 시작하며 항상 650ms의 등장·카운트를 유지합니다. 반복 충돌로 빠른 퇴장의 종료 시점이 늦춰지지 않으며, 떨어진 표시는 기존 위치와 정상 재생 시간을 유지합니다. 완전히 사라진 표시만 재사용합니다. 동작 줄이기 설정에서는 카운트나 전환 없이 최종 속도를 표시합니다.

이펙트 강도는 접촉점의 수직 속도와 에너지, 45% 가중치의 접선 속도, 회전 보정을 기준으로 계산합니다. 기존 강도 1까지의 반응은 유지하며, 그 이상은 `1 + ln(값)` 곡선으로 계속 증가합니다. 에너지·속도·회전 및 최종 강도의 상한을 제거해 강한 충돌끼리도 크기·파편 수·도달 거리가 달라집니다. 이펙트 발생 최소 속도 120px/s, 연속 충돌 간격 65ms, 실제 사각형의 물리 설정은 유지합니다.

로컬 서버를 실행한 뒤 `/effects.html`에서 A2 롤링 더스트, B2 리퀴드 스플래시, D2 연쇄 파열을 나란히 비교할 수 있습니다. A2는 눌린 구름의 윤곽과 내부 말림이 계속 바뀌고 작은 구름으로 분리됩니다. B2는 잉크 줄기가 늘어나 목이 끊어진 뒤 방울이 재분열하며 탄도 궤적을 따라갑니다. D2는 서로 맞붙은 면에 균열이 자라며 조각들이 분리·회전하고 다시 나뉩니다. 후반에는 선을 걷어 내거나 이동하는 절단면으로 형태를 지우며, 동일한 윤곽을 단순 축소해서 끝내지 않습니다.

세기·접촉 면·방향은 모든 스타일에 동일하게 적용합니다. 재생 속도, 일시정지, 시간 탐색, 새 패턴 기능으로 세부 동작을 살펴볼 수 있고 매 반복마다 새 재질·힘의 변형값을 생성합니다. 동작 줄이기 환경에서는 정지 화면으로 시작합니다. **이전 5안 보기** 또는 `/effects.html?collection=previous`로 A 만화 구름, B 잉크 스플래시, C 붓 참격, D 각진 파쇄(기본 사이트), E 압력 링도 비교할 수 있습니다.

스타일을 선택하고 **실제 사이트에서 휘둘러보기**를 누르면 `/?impact=스타일ID`에서 실제 사각형의 충돌에 해당 스타일을 사용합니다. 상단의 비교 링크로 선택 화면에 돌아올 수 있습니다. 선택은 URL에만 반영하며 기본 사이트의 스타일은 바뀌지 않습니다. 새 스타일도 충돌의 강도·접촉 폭·방향을 반영하고 화면 경계를 넘어 이어집니다. 랜덤값은 충돌 시 한 번 정하며, 그 값을 따라 매 프레임 윤곽·연결부·조각의 궤적을 계산해 형태가 변해도 깜빡이지 않습니다.

## 공·하트·별 충돌 효과 미리보기

`/bounces.html`에서 A **톡! 선 팝**, B **미니 선 폭죽**, C **통통 곡선**을 비교합니다. 클릭·폭죽 효과처럼 채워진 면이나 닫힌 외곽선 없이 불투명한 선만 사용합니다. A는 짧은 방사형 선, B는 휘어지는 탄도 궤적의 선 조각, C는 탄력 있게 휘는 짧은 곡선이며, 투명도 대신 선의 길이를 줄여 마무리합니다. 공·하트·별, 충돌 세기와 방향, 재생 속도를 바꿀 수 있고 시간 막대로 같은 실제 충돌의 각 시점을 살펴볼 수 있습니다. 세 안은 같은 물리 시뮬레이션의 접촉 지점·법선·충돌 직전 상대 속도를 공유하며, 새 패턴은 효과의 형태만 다시 생성합니다.

기본 사이트에는 A **톡! 선 팝**을 사용합니다. 충돌 응답과 속도 제한이 적용된 뒤 공의 속도 변화 중 접촉 법선 방향 성분을 측정합니다. 이 실제 튕김 속도를 기준으로 선의 길이·퍼지는 거리·개수가 달라집니다. 크기는 튕김 속도의 0.72제곱 곡선으로 부드럽게 커지며, 공 반지름의 0.7제곱 배율도 함께 반영합니다. 큰 공일수록 더 크게 퍼지며 반지름 60px 이후에도 계속 확대됩니다. 강도별 고정 크기나 크기 상한은 없습니다. 물리적인 튕김과 점수는 바꾸지 않습니다.

빠르게 움직이는 충돌에서는 접촉면의 이동·회전 속도를 이펙트에 전달하고, 이 이동 관성은 점차 줄어듭니다. 박스에 계속 붙이지 않으며 새 커서 움직임을 뒤늦게 따라가지 않습니다. A의 기본 재생 시간은 이동과 튕김 속도에 따라 약 460~600ms이며, 선별 등장 지연까지 포함해 이 시간 안에서 동작을 마칩니다. 현재 박스와 도형 내부에 덮인 선 구간은 실제 윤곽을 기준으로 가리며, 박스의 투명 배경이나 다른 이펙트는 덮어 그리지 않습니다. 좌우 경계를 넘는 박스도 같은 처리를 합니다. 처음 절반의 시간은 선이 펼쳐지는 동작을 보장한 뒤, 양쪽 물체가 효과 중심에서 충분히 멀어지면 선을 160ms 동안 줄여 퇴장시킵니다. 다시 가까워져도 해당 효과를 되살리지 않습니다. 물리 계산 도중 생긴 접촉도 프레임 끝의 경과 시간만큼 이펙트 위치와 재생 시간을 맞춥니다.

미리보기의 **장면**에서 기본 충돌, 함께 빠르게 이동, 박스로 밀어올리기를 바꿔 확인할 수 있습니다. **크기 (지름)**에서 24·48·96·128px을 비교할 수 있습니다. 시간 막대를 뒤로 이동해도 각 시점의 퇴장을 실제 궤적으로 다시 계산합니다.

**실제 사이트에서 시험하기**를 누르면 `/?bounce=pop`, `/?bounce=bubbles`, `/?bounce=spring`에서 사각형과 도형을 직접 부딪혀 비교할 수 있습니다. 새 효과는 바닥의 D 각진 파쇄 및 속도 표시와 별개입니다. 낮은 속도의 지지 접촉에는 나오지 않으며, 동작 줄이기 설정에서는 생략합니다.
